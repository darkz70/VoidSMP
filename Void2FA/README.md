# Void2FA

Двухфакторная аутентификация (2FA) для **Paper 26.2** через **Telegram-бота**.

Плагин сам содержит всю логику бота (long polling Telegram Bot API) — отдельный
бот-сервис писать не нужно. Достаточно создать бота у **@BotFather** и вставить
его токен в конфиг. Пока токен не указан, плагин **никого не блокирует**.

📌 **Для подключения бота позже:** [сохранённая инструкция, тексты BotFather,
сообщения и ТЗ отдельного бота](BOT_SETUP.md). Подключение сейчас не требуется.

---

## Возможности

- 🔐 Подтверждение входа через Telegram: **одноразовый код** и/или **кнопки** «✅ Подтвердить / ❌ Отклонить».
- 🧊 Заморозка до подтверждения: нельзя двигаться, писать в чат, использовать команды (кроме auth-команд), ломать/ставить блоки, взаимодействовать, выбрасывать предметы, кликать в инвентаре, телепортироваться; урон не проходит. Накладывается слепота.
- 🔗 Привязка аккаунта через одноразовый токен (`/2fa link` → боту `/link <код>` или ссылка `t.me/...?start=LINK_...`).
- ⏱️ Таймаут входа, лимит попыток, срок действия кода — всё настраивается.
- 🕹️ Два режима: `opt-in` (по желанию) и `required` (для всех).
- 🧠 «Сессии»: можно не спрашивать 2FA повторно при входе с того же IP в течение N минут.
- 🛡️ Право `void2fa.bypass` для доверенных игроков/админов.
- 🗣️ Все сообщения на русском и полностью настраиваются в `config.yml`.
- 📦 Без внешних зависимостей (собственный JSON-парсер, `java.net.http`).

## Быстрый старт

1. Положи `Void2FA-1.0.0.jar` (лежит в [`release/`](release/)) в папку `plugins/` сервера.
2. Запусти сервер — создастся `plugins/Void2FA/config.yml`.
3. Создай бота: напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получи **токен**.
4. Вставь токен в `config.yml`:
   ```yaml
   telegram:
     bot-token: "123456789:AAEx..."
   ```
5. Выполни в игре `/2faadmin reload` (или перезапусти сервер). В консоли появится
   «Telegram-бот подключён: @имя_бота».
6. Привяжи аккаунт: в игре `/2fa link` → открой бота и отправь `/link <код>`
   (или перейди по ссылке из сообщения).
7. Готово! При следующем входе бот пришлёт код и кнопки подтверждения.

> Пока `bot-token` пустой, плагин работает вхолостую и никого не блокирует —
> можно спокойно настроить всё заранее.

## Команды

| Команда | Описание |
|---|---|
| `/2fa` | Статус 2FA |
| `/2fa link` | Привязать Telegram |
| `/2fa unlink` | Отвязать Telegram |
| `/2fa on` / `/2fa off` | Включить / выключить 2FA |
| `/2fa code <код>` | Подтвердить вход кодом |
| `/2fa resend` | Выслать код повторно |
| `/2fa help` | Помощь |
| `/login <код>` | Быстрый ввод кода (алиас `/2fa code`) |
| `/2faadmin reload` | Перезагрузить конфиг и перезапустить бота |
| `/2faadmin status <игрок>` | Статус игрока |
| `/2faadmin reset <игрок>` | Сбросить привязку игрока |
| `/2faadmin enable <игрок>` | Включить 2FA игроку |
| `/2faadmin disable <игрок>` | Выключить 2FA игроку |

Алиасы: `/2fa` → `/tfa`, `/twofa`; `/2faadmin` → `/tfaadmin`.

### Команды бота (в Telegram)

| Команда | Описание |
|---|---|
| `/start` | Приветствие и инструкция |
| `/link <код>` | Привязать аккаунт (код из игры) |
| `/status` | Статус привязки |
| `/unlink` | Отвязать аккаунт |
| `/help` | Помощь |

## Права (permissions)

| Право | По умолчанию | Описание |
|---|---|---|
| `void2fa.use` | все | Использование `/2fa` и `/login` |
| `void2fa.admin` | OP | Админ-команды `/2faadmin` |
| `void2fa.bypass` | нет | Полный пропуск 2FA |

---

## Как это работает

1. Игрок заходит → если у него включена 2FA (или режим `required`), он замораживается.
2. Плагин шлёт в его Telegram одноразовый код и кнопки «Подтвердить / Отклонить».
3. Игрок либо вводит код в игре (`/login <код>` или просто числом в чат), либо жмёт кнопку в боте.
4. При успехе — разморозка; при отказе, таймауте или превышении попыток — кик.

Привязка хранится в `plugins/Void2FA/data.yml` (UUID ↔ Telegram ID).

## Конфигурация

Основные параметры (`config.yml` → `settings`):

| Параметр | По умолчанию | Описание |
|---|---|---|
| `mode` | `opt-in` | `opt-in` / `required` |
| `code-length` | `6` | Длина кода |
| `code-ttl-seconds` | `120` | Срок действия кода |
| `auth-timeout-seconds` | `90` | Время на подтверждение (потом кик) |
| `max-attempts` | `5` | Лимит неверных попыток |
| `session-minutes` | `0` | Не спрашивать 2FA повторно с того же IP N минут |
| `freeze` | `true` | Заморозка до подтверждения |
| `blindness` | `true` | Слепота до подтверждения |
| `lockdown-if-unavailable` | `false` | Не пускать никого, если бот недоступен |

Все сообщения (в игре, на экране кика и в Telegram) настраиваются в секции
`messages`. Цвета — через `&`. Плейсхолдеры: `{player}`, `{code}`, `{ip}`,
`{attempts}`, `{token}`, `{bot}`, `{url}`, `{minutes}`, `{state}`.

## Сборка из исходников

Обычная сборка через Gradle (нужен доступ к `repo.papermc.io`):

```bash
cd Void2FA
gradle build
# результат: build/libs/Void2FA-1.0.0.jar
```

Требуется JDK 25. Зависимость: `io.papermc.paper:paper-api:26.2.build.+`.

> Готовый `.jar` уже лежит в [`release/Void2FA-1.0.0.jar`](release/Void2FA-1.0.0.jar)
> и собран для Java 21+ (работает на Java 25 / Paper 26.2).

## Заметки о безопасности

- Код подтверждения — второй фактор: он приходит только в привязанный Telegram.
- Кнопки подтверждения проверяют, что нажавший — владелец привязанного аккаунта.
- Привязка и ввод кода работают только в **личных** чатах с ботом.
- Отвязать аккаунт во время незавершённого входа нельзя (защита от обхода).
- Токен бота хранится только в `config.yml` на сервере — не публикуй его.
- Для доверенных админов выдай `void2fa.bypass`, чтобы не блокировать их при сбое бота.
