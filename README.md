# VoidSMP

Плагин **VoidQuirks** — «причуды расколотых душ» для Paper **26.2**.

По легенде сервера: демон азарта украл души игроков и держит их в клетках лабиринта.
У освобождённых душ появились способности (баффы), но из-за расколотости — и дебаффы,
которые слабеют по мере восстановления души (уровни 1 → 3).

## Установка

1. Скачай свежий `VoidQuirks-x.x.x.jar` из раздела **Releases** (тег `ci-build` — автосборка последнего коммита).
2. Положи в папку `plugins` сервера Paper 26.2 (нужна Java 25).
3. Перезапусти сервер. Настройки — в `plugins/VoidQuirks/config.yml`.

## Команды

| Команда | Описание | Права |
|---|---|---|
| `/quirk set <игрок> <причуда> [уровень]` | выдать причуду (уровень 1–3, по умолчанию 1) | `quirks.admin` (оп) |
| `/quirk remove <игрок>` | снять причуду (чистит эффекты/инвентарь) | `quirks.admin` |
| `/quirk info [игрок]` | посмотреть свою/чужую причуду | все / админ для чужих |
| `/quirk list` | список всех причуд | `quirks.admin` |
| `/quirk reload` | перечитать config.yml | `quirks.admin` |

Причуды: `инженер`, `кот`, `бедрок`, `топор`, `скалк` (можно и по-английски).
Алиасы команды: `/quirks`, `/причуда`. Данные игроков — `plugins/VoidQuirks/players.yml`.

## Причуды по уровням

### 🔧 Инженер
| Ур. | Дебафф | Бафф |
|---|---|---|
| 1 | Слабость I (постоянная) | Шифт: сабтайтл с количеством редстоуна рядом (3×3): пыль, блоки, поршни |
| 2 | — | То же, зона 5×5, + нитки и таблички |
| 3 | Мясо нельзя: «Эльфийский желудок не может это переварить» + эффект голода | Зона 7×7 + отдельная строка про ТНТ и вагонетки с ТНТ (~10×10) |

### 🐱 Кот
| Ур. | Дебафф | Бафф |
|---|---|---|
| 1 | Вход в воду: 1.5 сердца урона + левитация 1 сек | Нет урона от падения (без эффекта плавного падения) + рыба даёт насыщение 5 сек |
| 2 | Вход в воду: 0.5 сердца + левитация 1 сек | То же, насыщение от рыбы 10 сек |
| 3 | — | То же + шифт показывает количество воды рядом (~10×10) |

### ⛏ Бедрок
| Ур. | Дебафф | Бафф |
|---|---|---|
| 1 | Весь инвентарь, кроме хотбара, — неизвлекаемые барьеры + бедрок в центре. При смерти не выпадают | При 3 иконках голода → 4 стейка (кд 30 мин) |
| 2 | Половина инвентаря (верхняя часть) + бедрок в центре | При 3.5 иконках → 5 стейков (кд 30 мин) + зомби/скелеты/пауки/криперы в 10 блоках получают 8 урона (кд 10 мин) |
| 3 | Только бедрок в центре | При 4 иконках → 16 стейков (кд 30 мин) + постоянные Скорость I и Регенерация I |

### 🪓 Топор
| Ур. | Дебафф | Бафф |
|---|---|---|
| 1 | Меч скрафтить нельзя; мечи до алмазного в инвентаре превращаются в палку | Убийство моба топором: 5% — Регенерация II на 1 сек |
| 2 | То же + можно есть только мясо, иначе отравление | Регенерация II на 2 сек (5%) |
| 3 | Только мясо, иначе отравление (мечи снова можно) | Убийство топором: 2% — голова моба + рывок: шифт с топором → «нажмите Shift + Ctrl» → телепорт в точку взгляда (до 20 блоков, цена 4 иконки голода) |

### 🌌 Скалк
| Ур. | Дебафф | Бафф |
|---|---|---|
| 1 | Можно есть только сырое мясо и гнилую плоть | ×2 опыта с мобов |
| 2 | + кости | Гнилая плоть даёт насыщение 2 сек |
| 3 | + кости, порох, слизь | Насыщение от гнили 6 сек + постоянные +2 HP |

## Сборка из исходников

Нужны JDK 25 и сеть. Из корня репозитория:

```bash
gradle build   # или настроенный gradle wrapper
# готовый jar: build/libs/VoidQuirks-0.1.0.jar
```

Также плагин собирается GitHub Actions при каждом пуше (`.github/workflows/build.yml`)
и публикуется в pre-release `ci-build`.

## Заметки по реализации

- «Единицы голода» в конфиге = иконки еды (1 иконка = 2 очка). Пороги 3 / 3.5 / 4 иконки.
- Сдвиг-сканы имеют антиспам-кулдаун (2 сек, настраивается).
- Запечатанные барьеры/бедрок помечены через PDC — их нельзя выкинуть, переложить,
  слить в контейнер или уронить при смерти; раскладка чинится автоматически каждые 2 сек.
- Постоянные эффекты (слабость, скорость/реген, +2 HP) восстанавливаются после молока/смерти.
- Рывок Топора: «Ctrl» детектится как клавиша спринта — надо присесть (Shift) и сразу
  нажать клавишу спринта с топором в руке.
