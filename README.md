# NetherScale

NetherScale — Paper-плагин для настройки масштаба координат порталов между обычным миром и Нижним миром. Лицензионная атрибуция исходного проекта сохранена в `LICENSE`.

## Paper 26.2: режим 1:1

По умолчанию X/Z переходят **1:1**, без ванильного масштаба 8:1. Работает для игроков и других сущностей. Порталы в Край и остальные переходы между измерениями не меняются.

Paper по-прежнему выполняет стандартный поиск или создание портала у рассчитанной точки; высота Y не масштабируется. Поэтому фактическое место выхода может немного отличаться, если рядом найден уже существующий портал.

### Настройка

После первого запуска плагин создаст `plugins/NetherScale/config.yml`:

```yaml
nether-coordinate-scale: 1.0
```

- `1.0` — нужный режим 1:1.
- `8.0` — ванильное соотношение: X/Z в Нижнем мире равны координатам обычного мира, делённым на 8.

После изменения настройки перезапустите сервер.

### Сборка и установка

Нужны **Java 25** и Maven. Соберите проект командой:

```sh
mvn clean package
```

Скопируйте `target/netherscale-1.0.0.jar` в папку `plugins/` сервера Paper 26.2 и перезапустите сервер.
