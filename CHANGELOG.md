# Changelog

Все значимые изменения в этом репозитории документируются здесь.

## VoidSpawnRates 1.0.0 — 2026-10-26

Первый выпуск плагина зон скорости спавна мобов для Paper 26.2.

* Зоны-кубоиды: выделение «палкой» (ЛКМ/ПКМ по блокам) или `pos1`/`pos2` с
  координатами; `resize` меняет границы уже сохранённой зоны.
* Множитель спавна `0.0 … max-multiplier` на зону + отдельные правила по
  конкретным мобам (`/spawnrate mob <зона> <тип> <множитель>`).
* Лимит мобов в зоне (`cap`) с опциональным удалением лишних, защитой
  именованных и седлаемых мобов и лимитом удалений за проход.
* Политика пересечения зон: `PRIORITY` / `MULTIPLY` / `STRICTEST` в config.yml.
* Постоянное хранение в SQLite (`data.db`, WAL, запись в отдельном потоке,
  синхронный flush при выключении) — зоны переживают рестарт, `/reload` и
  выгрузку чанков. Автоматический переход на `zones.yml`, если SQLite недоступен,
  и одноразовый импорт из старого YAML.
* Решение о спавне принимается на `PreCreatureSpawnEvent` (жёсткие запреты,
  моб вообще не создаётся) и `CreatureSpawnEvent` (вероятность и добавка
  мобов); индекс «мир → чанк → зоны» даёт O(1) на попытку спавна.
* Косметика: рамка зоны частицами (`show`/`hide`) и подпись с множителем в
  action bar для игроков внутри зоны.
* Юнит-тесты на чистую логику (геометрия зон, индекс чанков, арифметика
  спавна, нормализация записи хранилища) — без запуска сервера.
