# VoidOferta — оферта VDS Corp для VOID SMP

Отдельный плагин для **Paper 26.2**. Показывает игрокам официальную публичную
оферту **№ VDS-VOID-01** (VDS Corp под влиянием OZO™) в виде подписанной книги.

## Как это работает

1. **При следующем входе** каждый игрок, который ещё не подтверждал оферту,
   автоматически получает открытую книгу с полным текстом оферты.
   В книге ровно **42 страницы**: обложка, текст оферты, приложения
   к оферте — и страница 42 с цитатами Стэтхэма.
2. Внизу **42-й страницы** — кликабельная кнопка **[ ✔ ПРИНЯТЬ ОФЕРТУ ]**.
   Подтвердить нужно **ровно 1 раз**: принявшие записываются в
   `plugins/VoidOferta/accepted-players.yml` (UUID, ник, дата), и при
   следующих входах книга больше не беспокоит.
3. **`/oferta`** в любой момент открывает книгу снова — для повторного
   прочтения. Для уже принявших последняя страница показывает
   «✔ Вы уже приняли оферту» с датой, кнопка не требуется.
4. Пока оферта **не принята**, игрок не может ходить, взаимодействовать
   с миром и писать команды, кроме `/oferta` (отключается в конфиге —
   `freeze-until-accepted: false`). Администраторы (`voidoferta.admin`)
   заморозкой не блокируются.

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/oferta` | все | Открыть книгу оферты |
| `/oferta accept` | все | Принять оферту (то же, что кнопка в книге) |
| `/oferta status [ник]` | свой статус — все, чужой — админ | Проверить, принята ли оферта и когда |
| `/oferta reset <ник>` | админ | Сбросить подтверждение — при следующем входе игрок снова увидит книгу |
| `/oferta reload` | админ | Перечитать `config.yml` и `oferta.txt` без рестарта |

Права: `voidoferta.use` (по умолчанию у всех), `voidoferta.admin` (по умолчанию OP).

## Установка

1. Соберите плагин (см. ниже) или скачайте `VoidOferta-1.0.0.jar` из артефактов GitHub Actions.
2. Положите jar в `plugins/` сервера Paper 26.2 и перезапустите сервер.
3. Все, кто уже играет, при **следующем входе** увидят книгу и подтвердят оферту один раз.

## Настройка без перекомпиляции

После первого запуска в `plugins/VoidOferta/` появятся:

- `oferta.txt` — полный текст оферты. Редактируйте свободно: плагин сам
  порежет текст на страницы книги (по абзацам, не разрывая слова).
  Примените правки командой `/oferta reload`.
- `config.yml` — задержка открытия книги после входа, заморозка до принятия,
  заголовок/автор книги, размер страницы.
- `accepted-players.yml` — кто уже принял (не редактируйте вручную без нужды;
  для сброса есть `/oferta reset <ник>`).

⚠️ Если текст оферты **изменится по смыслу** и нужно, чтобы все подтвердили
заново: сотрите `accepted-players.yml` (или выполните `/oferta reset <ник>`
по каждому) и перезапустите сервер.

## Сборка

Нужны **JDK 25** (Paper 26.2 собран на Java 25, более старая javac не
прочитает paper-api) и Gradle:

```bash
cd VoidOferta
gradle build
# готовый плагин: build/libs/VoidOferta-1.0.0.jar
```

По умолчанию берётся последняя сборка Paper API `26.2.build.+`. Точную
версию можно задать явно:

```bash
gradle build -PpaperVersion=26.2.build.<номер>-<канал>
```

Также jar автоматически собирается GitHub Actions при каждом пуше
(workflow `.github/workflows/build-voidoferta.yml`, артефакт `VoidOferta-jar`).
