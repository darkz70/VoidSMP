# VoidSMP: Скалк (Fabric-мод)

Отдельный проект, отдельный стек — это **не** часть серверного плагина VoidQuirks
(тот работает на Paper и ставится в `plugins/`). Это настоящий **Fabric-мод** для
клиента/сервера на Minecraft **26.2**, собирается своим Gradle-билдом
(`fabric-mod/build.gradle.kts`), в CI — отдельным job'ом `build-fabric-mod`.

## Что внутри

- **Два наших скалк-биома** — `voidquirks:sculk_island` и `voidquirks:sculk_citadel`,
  JSON-файлы перенесены 1:1 из серверного датапака (`src/main/resources/sculk_datapack`
  в корне репозитория). Биомы данные, а не код — работают одинаково что в датапаке
  Paper-сервера, что здесь.
- **Настоящая скалк-древесина** — `voidquirks:sculk_log`, `sculk_leaves`, `sculk_planks` —
  это по-честному НОВЫЕ блоки (в отличие от серверного плагина, где это трюк с
  `NOTE_BLOCK`, потому что Paper-плагин не может регистрировать новые блоки, а
  Fabric-мод — может). Плюс `sculk_sapling` — пока простой предмет (без посадки/
  роста дерева, это можно добавить следующим шагом).
- **`/sculkvillage`** — мгновенно поднимает ванильную деревню (`/place structure
  minecraft:village_plains`, переиспользуем штатную механику) и тут же "скалкует"
  дубовую древесину в радиусе ~48 блоков (OAK_LOG/OAK_PLANKS/OAK_LEAVES → наши
  скалк-блоки). Право: уровень 2 (как у `/give`), для админов/операторов.

## Статус / ограничения первой версии

- Это **первая версия**, собранная и протестированная только через CI (нет
  локального игрового клиента для ручной проверки в этой песочнице) — если первая
  сборка упадёт, лог попадёт в GitHub Issue "CI failure log", буду чинить дальше.
- Саженец не растёт в дерево — это задел на будущее.
- Нет двери/лодки/таблички/люка из скалк-древесины — только брёвно/листва/доски (как в
  серверном плагине на момент портирования).
- `/sculkvillage` не строит деревню "с нуля" в скалк-теме — берёт готовую ванильную
  деревню и перекрашивает её дерево на скалковое (быстрее и надёжнее, чем писать свою
  генерацию структур с нуля).

## Установка

Собранный `VoidSculk-Fabric-<версия>.jar` (артефакт `VoidSculk-Fabric-jar` в CI, или
прикреплён к релизу `ci-build`) кладётся в `mods/` папку Fabric-сервера/клиента с
установленным Fabric Loader 0.19.3+ и Fabric API 0.160.0+26.2 для Minecraft 26.2.
